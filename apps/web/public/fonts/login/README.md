Login typography

Visual reference requested by the product owner:
https://app.useatiende.ai/rentas/login?lang=es

Fraunces (400), Instrument Sans (400–600) and IBM Plex Mono (400) are
self-hosted for the login only. Their SIL Open Font Licenses are included.
The existing workspace fonts and the Rovaq logo are unchanged.

The corresponding canvas renderer lives in src/components/login/particle-engine.js.
It contains drawing code only; no authentication, analytics, sessions or provider
configuration from the reference application is included.
