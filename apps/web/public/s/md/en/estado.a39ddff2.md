# Service status

How to tell which version is deployed and how to report a problem. It is not an availability commitment.

## What we publish here

The service exposes a public identifier of the deployed version: the version number and the build identifier. You can read it at rovaq.ai/api/health/version. This page is static and does not show that value live; the identifier only says which build is in use and does not say whether each part of the service is working.

## What this page is not

- It is not a service level agreement or an availability commitment.
- It is not a live monitor or an incident history. We do not publish availability percentages or response times.
- It does not replace the Data trust screen, which inside the product says what date your data reaches, what it covers and what is not known.

## How to report a problem

To report a problem, use the contact on https://rovaq.ai/en/request-access This page does not set a response time.

## What to include in the report

- The screen where it happened and what you expected to see.
- What happened instead, with the approximate time and your time zone.
- The version shown at rovaq.ai/api/health/version, if you checked it.
- No passwords and no personal data of your customers: we do not need them to understand the problem.
