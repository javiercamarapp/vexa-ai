## Resultado
Crear Next.js TypeScript en Vercel-compatible runtime, Supabase Auth/Postgres/Storage y RLS por tenant; pipeline GitHub Actions con verificación separada.

## Pasos
1. Resolver versiones actuales desde documentación instalada/catálogos y fijar lockfile; no copiar latest de memoria.
2. Implementar login/logout, membership en DB y selector de organización sin confiar tenant_id del body.
3. SQL migrations con claves tenant-aware y RLS default deny; Storage privado.
4. Diseño base accesible, sidebar, navegación y estados vacío/error/stale/loading.
5. CI lint/typecheck/unit/SQL integration/build; secretos de preview mínimos, ninguna clave servicio al browser.

## Criterios observables
- Login de A no lista/lee/escribe B aun con IDs conocidos; membership revocada bloquea siguiente request.
- Error DB da unavailable, no dashboard lleno de ceros.
- Build y arranque local reales; CI remoto sólo se afirma al ejecutarse.
